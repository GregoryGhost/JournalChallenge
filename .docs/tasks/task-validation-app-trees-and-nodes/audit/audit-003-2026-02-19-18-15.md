## 1. Summary of Work
Updated all handler test method names in `JournalChallenge.Application.Tests` to follow the mandated `Test<Scenario>Should<Expectation>` convention. This ensures consistency and explicit expectations across the test suite as required by the `architecture-spec.md`.

## 2. Key Changes Implemented

### 2.1 Test Method Renaming
- **`GetTreeQueryHandlerTests.cs`**:
    - `HandleAsync_ShouldCreateTreeAndRootNode_WhenTreeDoesNotExist` → `TestTreeDoesNotExistShouldCreateTreeAndRootNode`.
- **`CreateNodeCommandHandlerTests.cs`**:
    - `ShouldFail_WhenAddingSecondRoot` → `TestAddingSecondRootShouldBeFailure`.
    - `ShouldFail_WhenNameExistsAmongSiblings` → `TestNameExistsAmongSiblingsShouldBeFailure`.
- **`RenameNodeCommandHandlerTests.cs`**:
    - `HandleAsync_ShouldSucceed_WhenValid` → `TestValidRenameShouldBeSuccess`.
    - `HandleAsync_ShouldFail_WhenNameExistsAmongSiblings` → `TestNameExistsAmongSiblingsShouldBeFailure`.
- **`DeleteNodeCommandHandlerTests.cs`**:
    - `HandleAsync_ShouldFail_WhenHasChildrenAndNotForced` → `TestHasChildrenAndNotForcedShouldBeFailure`.
    - `HandleAsync_ShouldSucceed_WhenForcedDeletionIsTrue` → `TestForcedDeletionIsTrueShouldBeSuccess`.

## 3. Verification & Testing
- **Test Results**: All 21 tests in `JournalChallenge.Application.Tests` passed after renaming.
