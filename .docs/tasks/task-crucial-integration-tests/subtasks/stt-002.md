# Subtask: Business Constraint Enforcement (stt-002)

## Objective
Ensure that violating business rules triggers the correct `SecureException` responses.

## Actions
- [ ] Create test case: Root Constraint - Attempt to create a second root in the same tree.
- [ ] Create test case: Sibling Uniqueness - Attempt to create two nodes with the same name under the same parent.
- [ ] Create test case: Safe Deletion - Attempt to delete a parent node with children without the `isForcedDeletion` flag.

## Verification
- Confirm each test triggers a 500 response.
- Confirm response body follows the `SecureException` JSON format.
- Confirm specific error messages match the spec.
