# Subtask: Health Check & Infrastructure Setup (stt-000)

## Objective
Enable a standard health check endpoint in the API and prepare a version-pinned Docker testing configuration.

## Actions
- [ ] Update `Program.cs` to map the `/health` endpoint using `app.MapHealthChecks("/health")`.
- [ ] Ensure `AddHealthChecks()` is called in the `Infrastructure.Core` initialization (if not already part of the main startup).
- [ ] Create `docker.testing.yaml` with:
    - [ ] `postgres` image pinned to a specific version (e.g., `postgres:15-alpine`).
    - [ ] `newman` image pinned to a specific version.
    - [ ] Native Docker health check for the database (`pg_isready`).
    - [ ] Native Docker health check for the API using `curl -f http://localhost:8080/health`.

## Verification
- Run the API locally and confirm `GET /health` returns `200 OK`.
- Run `docker compose -f docker.testing.yaml config` to verify the YAML structure and image versions.
