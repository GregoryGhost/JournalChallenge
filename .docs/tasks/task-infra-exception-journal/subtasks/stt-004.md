# stt-004: Middleware: Persistence & Response Formatting

## Objective
Complete the middleware by logging details to the DB and formatting the HTTP response.

## Tasks
- [ ] Inject `IApplicationDbContext` into the middleware (or use a factory).
- [ ] Persist all captured details (ID, Type, Message, StackTrace, Params) to the `ExceptionJournal` table.
- [ ] Implement response formatting logic:
    - `SecureException` -> `{"type": "Secure", "id": "...", "data": {"message": "..."}}`.
    - Other exceptions -> `{"type": "Exception", "id": "...", "data": {"message": "Internal server error ID = ..."}}`.
- [ ] Ensure HTTP status code is always 500.
