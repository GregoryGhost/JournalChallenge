# stt-002: Custom Result Mapping

## Objective
Implement the logic to map Application `Result` failures to specific exceptions required by the presentation layer.

## Tasks
- [ ] Implement `CustomResultsHandler` in `JournalChallenge.Infrastructure.Core/Implementations/`.
- [ ] Map `ErrorType.Secure` to a new `SecureException`.
- [ ] Map all other `ErrorType` values to a generic `Exception` with the domain error message.
- [ ] Register the handler in Dependency Injection.
