# stt-003: Middleware: Context Capture & ID Generation

## Objective
Implement the initial stage of the global exception middleware to capture request context.

## Tasks
- [ ] Create `ExceptionMiddleware` in the Presentation project.
- [ ] Implement logic to buffer the HTTP request body to allow multiple reads.
- [ ] Generate a unique `long` Event ID for every handled exception.
- [ ] Extract and store Query String and Body parameters as stringified JSON.
